Reproduce

From a checkout of the repository. A dry run calls no model and costs nothing.

Run the unit tests

python3 -m unittest discover -s tests

Check the fixtures against their specifications

python3 tools/validate_fixtures.py

Confirm each model route answers in isolation

python3 -m common.probe --models opus-5.5,haiku-5.5 --mark-verified

Dry-run the contract-review experiment

python3 kestrel-injection-study/harness/experiment.py run --models opus-5.5,haiku-5.5 --reps 5 --dry-run

Report an error

If a number here does not match the raw records, or a claim goes further than the data, write to the author or open an issue. Confirmed errors are fixed in the manuscript and added to the corrections.

To cite the paper or the data, use the entries on the paper page.
